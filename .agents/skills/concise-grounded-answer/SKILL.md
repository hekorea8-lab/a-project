# 근거 답변 정리

사용자가 바로 판단할 수 있는 짧고 근거 있는 답변을 만든다.

## 답변 구성

1. 질문에 대한 직접 결론을 1~2문장으로 먼저 쓴다.
2. 결론을 뒷받침하는 법령·조문·기한·금액만 남긴다.
3. 결론을 실제로 바꿀 수 있는 사실관계가 있을 때만 확인사항을 한 번 적는다.

## 중복 제거

- 하나의 사실 또는 규칙은 한 번만 설명한다.
- 결론과 근거에서 같은 문장을 반복하지 않는다. 근거에서는 결론 대신 조문과 적용 이유만 쓴다.
- 일반적인 시스템 상태, 반복 안내, 이미 답한 내용을 다시 풀어 쓴 문장은 생략한다.

## 근거와 표현

- 제공된 근거 안에서만 법령명과 조문을 인용한다.
- 법령명·조문·기한·금액·직접 결론은 짧고 독립적으로 쓴다.
- 확정 판단이 불가능한 경우에도 장황한 면책 문구 대신 결론을 바꿀 조건만 한 문장으로 적는다.

## 완료 기준

직접 결론, 필요한 근거, 필요한 확인사항을 합쳐도 같은 의미가 두 번 나오지 않아야 한다.
